# 가이드 화면 캡처

모든 공개용 이미지 자산은 이 디렉토리에 보관합니다. 본문 안내: [가입부터 설정까지](../../docs/setup.md).

캡처일: 2026-11-16. GitHub·Google Sheets·ChatGPT 웹의 실제 화면입니다. 저장소 이름과 가상 금액은 검증용 예시이며 개인 금융 자료가 아닙니다. 계정 이메일·개인 시트 URL/ID·채팅 목록은 공개용 캡처에서 제외합니다. 계정 연결·권한 화면 전체를 공개하지 않습니다.

플러그인 이미지는 이미 설치된 환경의 예시입니다. 처음 사용하는 계정에서는 설치·연결 버튼이 보일 수 있습니다. 검증용 저장소가 이미지에 보이더라도 사용자는 본인 이름의 새 사본을 만듭니다. 예시 저장소 주소를 연결 대상으로 사용하지 않습니다.

서비스 화면이 달라지면 실제 화면을 다시 확인하고 필요한 영역만 새로 캡처합니다. 이미지와 본문 캡션을 함께 갱신하며, 이메일·개인 링크·개인 문서 목록이 들어오지 않았는지 이미지 자체를 열어 검토합니다. 이미지에 포함된 가상 거래는 실제 재무 상태를 뜻하지 않습니다.

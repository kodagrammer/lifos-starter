# 가상 예제와 예상 결과

모든 자료는 설명을 위해 새로 만든 가상 거래입니다. 실제 인물·계좌·금액에서 추출하지 않았습니다. 별도 연습 스프레드시트에만 적용합니다.

## 준비

1. 공통 양식으로 `lifos 연습용 — 가상 자료`를 만듭니다.
2. BANK-001/SAVE-001을 연습용 가상 본인 계좌로 활성화합니다. 나머지는 후보로 둡니다.
3. 결제수단에는 가상카드 별칭을 사용하고 카드대금 출금 계좌는 BANK-001로 설정합니다. 실제 잔액은 만들지 않습니다.
4. 기준통화 KRW, 시작월과 조회 선택월은 2000-01-01로 설정합니다.
5. [가상 원장](ledger.csv)의 A:P와 V:W만 입력하고 Q:U는 시트 수식이 계산하게 합니다. CSV의 Q:U 빈칸으로 기존 수식을 덮어쓰지 않습니다.

|---|---|---:|---:|---:|
| DEMO-001 | 소득 | 1,000,000 | 1,000,000 | 0 |

모두 2000년 1월이며 환불은 DEMO-002를 참조합니다. 기초 잔액 자료가 없으므로 이 예제로 실제 계좌 잔액이나 순자산까지 확정하지 않습니다.

## 검증 시나리오

- 같은 CSV를 다시 적용: 신규 0건, 기존 5건 유지, 합계 무변경.
- 같은 원천 키의 금액을 바꿔 재제공: 기존 ID 정정 후보이며 신규 거래로 추가하지 않음. 사유 확인 후 정정·이력·재계산.
- 2000-01-06의 실제 별개 가상 구매 100,000원, 고유 키: 별개 거래 유지. 순소비는 180,000원. 확인 후 이 추가 시험은 별도 사본에서 수행.
- 금액 또는 용도가 불명확한 가상 거래: 확인필요이며 확정 합계에 미포함.
- 다른 달 환불: 환불일과 연결 ID를 보존하고 기본 정책상 환불 발생월 순소비에서 차감.
- 기준통화 외 거래: 원문 통화 보존, 기준통화 집계에 단순 합산하지 않음. 외화 건수에 표시.
- 분류 이름 변경: 같은 ID의 조회 이름이 바뀌며 거래 금액은 유지.
- 분류 사용 중지: 과거 조회는 유지하고 신규 후보에서 제외.

이 문서는 기대 동작입니다. 실제 Sheets·AI 연결에서 수행하기 전에는 라이브 검증 완료로 표시하지 않습니다.

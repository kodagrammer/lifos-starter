# 연결·저장 문제 해결

| 증상 | 확인할 일 | 다음 행동 |
|---|---|---|
| Use this template이 없음 | 배포자가 Template repository를 켰는지 | 배포자에게 설정 요청. Fork로 우회하지 않기 |
| AI가 개인 저장소를 못 읽음 | GitHub 연결 계정·허용 저장소 | 내 계정·개인 저장소를 연결에 추가하고 새 대화에서 재확인 |
| 시트가 안 보임 | Google 연결 계정과 파일 소유 계정 | 같은 계정인지 확인. 가계부 URL을 직접 전달 |
| 읽기는 되지만 저장 불가 | 쓰기 도구와 권한을 구분했는지 | 아래 수동 적용. 전체 공개로 바꾸지 않기 |
| 파일을 고쳤는데 GitHub에서 안 보임 | 로컬 수정만 되었는지 | 원격 반영 여부를 확인하고 미저장으로 표시 |
| 거래를 다시 넣을 때 중복 발생 | 기존 ID·원천키를 읽었는지 | 추가 중단, 기존·신규 대응표 확인 후 정정 |
| 날짜가 월별 조회에 안 나옴 | 일자가 텍스트인지 | 날짜 값으로 정규화하고 Q열 결과 재확인 |
| 수식에 #REF!가 표시됨 | 배열 출력 아래 값이 있는지 | 실제 입력을 보존·이동한 뒤 출력 공간 확보 |
| 수식에 #ERROR!가 표시됨 | 지역·구분자·따옴표·탭 이름 | 새 연습 시트에서 같은 수식부터 시험 |
| 빈 시트 합계가 0원임 | 실제 자료를 수집했는지 | 자료 미확인 상태 유지. 수입·소비 없음으로 확정 금지 |
| 새 대화가 이전 설정을 모름 | 개인 파일 원격 저장 여부 | 이어가기 프롬프트와 개인 URL 두 곳 전달 |

## 쓰기 도구가 없을 때의 수동 적용

같은 저장 위치를 유지하면서 AI가 만들고 사람이 적용합니다. 자동 저장이 완료된 것처럼 표시하지 않습니다.

### GitHub 파일

1. AI에게 `저장할 경로와 파일 전체 내용을 제공해줘`라고 요청합니다.
2. 내 Private 저장소에서 파일을 엽니다. 기존 파일은 연필 편집 버튼, 새 파일은 **Add file → Create new file**을 선택합니다.
3. 경로와 내용을 입력하고 **Preview**로 확인합니다.
4. **Commit changes**를 눌러 변경 내용을 저장합니다. 분기·PR을 요구하는 저장소라면 화면 안내대로 완료합니다.
5. 파일 화면을 다시 열고 내용이 반영되었는지 확인합니다. AI도 읽을 수 있으면 재조회하게 합니다.

### Google Sheets 셀

1. AI에게 `대상 탭·시작 셀·붙여넣을 표를 제공해줘. 계산 영역은 제외해줘`라고 요청합니다.
2. [안전 입력 안내](safe-input.md)에 따라 텍스트 열을 먼저 일반 텍스트로 설정합니다. 수식처럼 보이는 문자열은 문자로 개별 입력하고, 원문 탭·줄바꿈이 있는 표는 일괄 붙이지 않습니다. 계산 영역과 숫자·날짜 열은 구분합니다.
3. 원천 텍스트가 수식으로 실행되지 않고 글자 그대로 저장되었는지, 인접 셀이 바뀌지 않았는지 확인합니다. 날짜·금액·ID가 올바른 열에 들어갔는지 확인합니다. 쓰기 전후 건수와 합계를 비교합니다.
4. AI가 읽을 수 있으면 재조회하게 합니다. 읽을 수 없으면 실제 셀 결과를 내가 확인해 전달하고 `사용자 수동 확인`으로 남깁니다.

공식 안내: [GitHub 파일 편집](https://docs.github.com/en/repositories/working-with-files/managing-files/editing-files).

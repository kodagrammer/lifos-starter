# 업데이트와 영역 확장

## 원본 업데이트 적용

템플릿으로 만든 개인 저장소는 원본과 별개입니다. 자동 동기화를 가정하지 않습니다.

1. 공개 원본의 CHANGELOG에서 변경 범위와 버전을 확인합니다.
2. 내 개인 운영지침이 가리키는 버전 관리 위치와 개인 지침을 확인합니다.
3. 바뀐 공통 문서와 양식만 비교합니다. 운영 중인 개인 파일·계좌·분류·원장을 초기값으로 덮어쓰지 않습니다.
4. 새 수식이나 필드 변경은 가상 연습 시트에서 먼저 확인합니다.
5. 기존 데이터 영향·개인 정책 충돌을 검토한 뒤 필요한 변경만 적용합니다.
6. 재조회 검증을 마치고 적용한 버전과 차이를 기록합니다. 일부만 적용했다면 전체 버전 적용 완료로 표시하지 않습니다.

공개 개선안에는 일반화한 지침과 가상 재현 사례만 제출합니다. 개인 저장소 전체를 공개 fork나 공개 PR로 옮기지 않습니다.

## 투자·커리어 확장

현재 구현 영역은 `system/finance/`입니다. 향후 투자 지침은 `system/investing/`, 커리어 지침은 `system/career/`로 추가할 수 있습니다. 지금 빈 기능 폴더나 미완성 분석 기능을 만들 필요는 없습니다.

새 영역마다 목적, 지침, 양식, 개인 설정, 정본 위치를 정의합니다. 공동 지침과 장기 기록은 GitHub에 둡니다. 수시 갱신할 표는 Google Sheets에 두고 개인 profile에 위치만 연결합니다. 같은 수치나 상태를 여러 곳에서 독립 갱신하지 않습니다.

투자 확장 시 가계부의 투자 원금 이동과 투자 시트의 입금을 거래 ID 등으로 연결하고 두 곳의 수입·수익에 중복 합산하지 않습니다.

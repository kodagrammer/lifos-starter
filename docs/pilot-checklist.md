# 비개발자 파일럿 체크리스트

이 파일은 시험 절차입니다. 체크가 비어 있는 것은 아직 시험하지 않았다는 뜻입니다. 개인정보·실거래 캡처를 공개 피드백으로 수집하지 않습니다.

- [ ] GitHub 계정 생성·인증을 완료했다.
- [ ] README만 보고 Template에서 내 Private 저장소를 만들었다.
- [ ] 소유자·Private 표시·필수 파일을 확인했다.
- [ ] Google 계정으로 빈 가계부를 만들고 공유 범위를 제한했다.
- [ ] AI의 GitHub/Google Drive 연결을 설정했다.
- [ ] AI가 실제 파일·탭 이름을 읽었고 읽기·쓰기 권한을 구분했다.
- [ ] 신규/기존 경로를 실제 상황에 맞게 선택했다.
- [ ] 신규: 별도 가상 연습 시트에서 5건을 입력했다.
- [ ] 신규: 수입 1,000,000원·순소비 80,000원을 실제 시트에서 확인했다.
- [ ] 같은 자료를 다시 입력했을 때 신규 0건이었다.
- [ ] 계좌 후보 중 필요한 것만 활성화하고 분류 하나를 수정했다.
- [ ] 기존: 원본 진단 동안 셀·수식이 바뀌지 않았다.
- [ ] 기존: 현재 분류·부호·탭 방식을 반영한 개인 운영지침을 검토했다.
- [ ] 기존: 선택한 기능을 복사본에서 검증하고 선택 범위만 적용했다.
- [ ] 기존: 미지원 기능을 구분하고 구조 변경 시 쓰기가 중단되는지 확인했다.
- [ ] 운영 원장에는 가상 거래가 섞이지 않았다.
- [ ] 실제 거래 한 건을 개인 환경에 기록하고 저장 결과를 확인했다.
- [ ] 새 대화에서 같은 개인 설정·거래를 다시 읽었다.
- [ ] 미수집 자료가 있으면 부분점검으로 표시했다.
- [ ] GitHub 수동 저장 또는 실제 원격 저장을 확인했다.
- [ ] 첫 실제 월간 점검을 수행했다. 초기 설정과 별도 검증이다.

기록할 항목: 막힌 단계 / 이해하지 못한 표현 / 도움 요청 횟수 / 소요 시간 / 문서 수정 사항. 개인 금융 값은 기록하지 않습니다. 구두 설명이 필요했다면 해당 문서를 수정하고 같은 단계를 다시 시험합니다.

- [ ] 선택한 입력 경로별 안전 입력 무해한 시험을 수행하고 원천 셀의 실제 값·수식 여부를 확인했다.

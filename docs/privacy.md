# 개인정보와 저장 위치

## 공개 원본에 넣는 것

공통 지침, 빈 양식, 실제 사람과 무관한 가상 예제, 시작 프롬프트만 넣습니다. 실제 계좌 구성·내역을 이름만 가려 예제로 쓰지 않습니다. 개인 시트 링크·문서 ID·화면 캡처·인증정보를 공개하지 않습니다.

## 개인 Private GitHub에 넣는 것

개인 정책, 가계부 위치, 설정 진행 상태, 장기 보관할 회고와 결정 기록을 둡니다. 잔액·거래·개인 분류표의 운영 정본은 Sheets입니다. 고정 수치가 필요한 장기 기록을 따로 요청하면 해당 시점·범위·근거를 표시합니다.

Private 저장소도 연결한 AI·앱과 부여한 협업자의 접근 범위를 확인합니다. 공개 원본에 제출할 개선안에는 개인 파일과 기록을 포함하지 않습니다.

## Google Sheets에 넣는 것

계좌 별칭·잔액·분류·거래·자료 수집 상태·정정 이력·월간 점검을 둡니다. **공유 → 일반 액세스: 제한됨**으로 유지하고 필요한 계정만 허용합니다. AI 연결 문제를 해결하려고 전체 공개나 웹 게시를 켜지 않습니다.

금융기관 로그인 비밀번호, 일회용 인증번호, 보안카드, 전체 계좌번호는 기록하지 않습니다. 원본 명세서는 개인이 통제하는 비공개 위치에 보관하고 AI에 필요한 항목만 전달합니다. 파일의 주민번호·주소·인증정보는 제공 전에 제거합니다.

## 잘못 공개했을 때

새 개인정보 입력을 멈추고 노출된 자료와 범위를 확인합니다. 공개 파일을 지워도 이력·복사본이 남을 수 있습니다. 노출된 비밀번호·토큰은 서비스에서 폐기·재발급합니다. 저장소나 시트의 접근 범위를 즉시 바로잡고, 과거 공개 데이터가 완전히 사라졌다고 가정하지 않습니다.

`.gitignore`는 앞으로 추적하지 않을 파일의 규칙입니다. 이미 올린 파일이나 Git 이력을 지우지 않습니다.

## 원천 데이터의 안전한 저장

[안전 입력 지침](safe-input.md)을 따릅니다. 원천 텍스트를 수식으로 해석하지 않으며 자동 입력은 RAW/명시적 문자열을 사용합니다. 수동 입력·외부 CSV·정정 이력도 같은 기준으로 확인합니다. 도구의 안전한 쓰기·수식 여부를 확인할 수 없으면 적용을 보류합니다.

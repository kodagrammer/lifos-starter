# 월간 점검 요청

```text
개인 finance-layout.md의 지원 기능·입력 위치·집계 기준을 먼저 확인해줘.
실제 시트가 지침과 달라졌으면 영향받는 쓰기를 멈추고 변경점을 알려줘.
내 개인 GitHub 저장소: [URL]
내 Google Sheets 가계부: [URL]
점검할 달: [YYYY-MM]

지침과 개인 설정을 읽고 해당 월을 점검해줘.
개인 운영지침의 자료 수집 관리 위치에서 기대한 계좌·카드·기간과 실제 수집 범위를 대조해줘.
개인 운영지침의 확인 상태·통화·귀속 기준에 맞게 수입과 순소비를 계산하고
중복·이체·카드대금·환불 연결·분류·통화를 확인해줘.
월을 판별할 수 없는 날짜 오류와 금액·필수값 누락도 따로 찾아줘.
미확인 0건을 자료 완비로 간주하지 마.
미수집 자료와 미확인 거래, 확인된 결과를 구분해서 알려줘.
내가 답해야 하는 질문을 묶어서 제시해줘.
검증 결과는 개인 운영지침에 지정된 Google Sheets 점검 위치에 저장해줘.
해당 위치가 없으면 보완안을 먼저 제안하고 임의 탭을 만들지 마.
미완료이면 부분점검으로 표시하고 전체 재무 마감이라고 표현하지 마.
```

AI는 월이 끝났는지, 자료범위가 완비되었는지, 미결이 해소되었는지와 사용자 사실 확인을 대조한다. 점검 전후의 원장·수식 결과를 실제 재조회한다. 같은 월의 점검 정정은 변경이력을 보존한다.

장기 회고를 GitHub에 남기려면 사용자가 별도로 요청한 내용만 기록한다. 매번 거래·합계를 복사해 두 번째 원장을 만들지 않는다.

원천 데이터 쓰기 전 `docs/safe-input.md`를 읽는다. 원천 텍스트·날짜·숫자·신뢰한 계산 수식을 분리하고 선택한 쓰기 경로의 안전성 및 사후 실제 저장값·수식 여부를 확인한다. 확인할 수 없으면 해당 쓰기를 보류한다.

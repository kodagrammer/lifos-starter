# 거래 기록 요청

아래 요청을 복사하고 내 주소와 내용을 채웁니다. 연결된 같은 대화에서는 주소를 반복하지 않아도 됩니다.

```text
개인 finance-layout.md의 지원 기능·입력 위치·집계 기준을 먼저 확인해줘.
실제 시트가 지침과 달라졌으면 영향받는 쓰기를 멈추고 변경점을 알려줘.
내 개인 GitHub 저장소: [URL]
내 Google Sheets 가계부: [URL]

공동 지침과 개인 설정을 읽고 아래 거래를 기록해줘.
[날짜 / 내용 / 금액 / 결제수단 별칭 / 내가 부담한 범위]

원장과 원천키를 비교해 추가·정정·중복제외·무변경을 구분해줘.
모르는 사실은 확인필요로 남기고 필요한 질문만 해줘.
카드대금·내 계좌이체를 소비로 더하지 말고 환불은 원거래와 연결해줘.
계산 영역을 보호하고 실제 반영한 셀과 집계를 다시 읽어 검증해줘.
거래 수치는 Google Sheets에만 저장해줘.
```

AI는 `system/finance/rules.md`를 따른다. 원장을 읽을 수 없으면 중복 여부를 확인했다고 말하지 않는다. 입력 권한이 없으면 해당 시트·열의 붙여넣을 값과 적용 후 확인 방법을 제공한다.

원천 데이터 쓰기 전 `docs/safe-input.md`를 읽는다. 원천 텍스트·날짜·숫자·신뢰한 계산 수식을 분리하고 선택한 쓰기 경로의 안전성 및 사후 실제 저장값·수식 여부를 확인한다. 확인할 수 없으면 해당 쓰기를 보류한다.

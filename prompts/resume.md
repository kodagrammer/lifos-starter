# 새 대화에서 이어가기

```text
개인 finance-layout.md의 지원 기능·입력 위치·집계 기준을 먼저 확인해줘.
실제 시트가 지침과 달라졌으면 영향받는 쓰기를 멈추고 변경점을 알려줘.
내 개인 GitHub 저장소: [URL]
내 Google Sheets 가계부: [URL]

lifos 가계관리를 이어서 도와줘.
저장소의 AGENTS.md, personal/profile.md, personal/progress.md와
가계관리 지침을 읽어줘.
개인 운영지침에 지정된 실제 설정·계좌·자료 수집·최근 변경 위치를 확인해줘.
초기 양식이나 예제 데이터로 운영 자료를 덮어쓰지 마.
온보딩 진행 상태와 운영 중 미확인 거래를 구분해줘.
실제로 읽은 범위, 현재 위치, 필요한 다음 행동을 짧게 알려줘.
기존 대화의 기억으로 연결이나 저장 성공을 가정하지 마.
```

원천 데이터 쓰기 전 `docs/safe-input.md`를 읽는다. 원천 텍스트·날짜·숫자·신뢰한 계산 수식을 분리하고 선택한 쓰기 경로의 안전성 및 사후 실제 저장값·수식 여부를 확인한다. 확인할 수 없으면 해당 쓰기를 보류한다.

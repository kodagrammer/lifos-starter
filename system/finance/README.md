# 가계관리 영역

목적은 실제 수입·본인 소비·자금이동을 구분하고, 빠진 자료와 확인할 일을 알 수 있게 하는 것입니다.

| 위치 | 정본 |
|---|---|
| GitHub의 이 폴더 | 공통 규칙과 초기 양식 |
| 개인 GitHub `personal/profile.md` | 시트 위치와 개인 정책 연결 |
| 개인 GitHub `personal/progress.md` | 초기 설정·환경 연결의 진행 상태 |
| Google Sheets `설정`, `계좌관리` | 개인별 설정·분류·계좌·잔액 |
| Google Sheets `거래원장` | 실제 거래와 원천·확인 상태 |
| Google Sheets `자료범위`, `변경이력`, `월간점검` | 수집·정정·점검의 운영 정보 |
| Google Sheets `가계부` | 원장에서 계산한 조회 화면 |

기존 시트는 개인 `finance-layout.md`의 실제 탭·위치·집계 기준을 따릅니다. 위 탭 이름은 신규 추천 구성의 예시입니다. 기존 시트 진단은 [이 절차](../../docs/existing-sheet.md)를 따릅니다.

먼저 [공통 규칙](rules.md)과 [시트 구성](../../docs/sheets-setup.md)을 읽습니다. 초기 CSV는 설정의 출발점이며 운영 중인 시트를 덮어쓰는 파일이 아닙니다.

투자·연금 계좌로의 원금 이동은 기록할 수 있습니다. 종목 관리·투자 성과·전체 순자산 확정은 이 버전에 포함하지 않습니다.

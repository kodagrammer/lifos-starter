# 초기 설정 진행 양식

이 파일을 개인 Private 사본에서 `personal/progress.md`로 복사합니다. 상태는 미시작/진행중/완료/대기를 사용하고 완료 근거가 있을 때만 완료로 바꿉니다.

| 단계 | 상태 | 확인 근거 |
|---|---|---|
| 개인 Private 사본 생성 | 미시작 | 아직 확인하지 않음 |
| 운영 가계부 생성·접근 제한 | 미시작 | 아직 확인하지 않음 |
| GitHub 읽기·원격 저장 | 미시작 | 자동/수동 적용 방법과 검증 결과 기록 |
| Sheets 읽기·쓰기 | 미시작 | 자동/수동 적용 방법과 검증 결과 기록 |
| 별도 가상 연습·중복 검증 | 미시작 | 아직 확인하지 않음 |
| 신규 추천 구성 또는 기존 시트 진단·개인 운영지침 확정 | 미시작 | 아직 확인하지 않음 |
| 첫 실제 기록·재조회 | 미시작 | 거래 수치 없이 검증 여부만 기록 |
| 새 대화에서 재개 | 미시작 | 아직 확인하지 않음 |

# 개인 설정 파일

공개 원본에는 이 README와 예제 파일만 있습니다. 개인 Private 사본에서 AI와 함께 다음 파일을 만드세요.

- `profile.md`: 개인 저장소·가계부 위치와 장기 정책 연결.
- `finance-layout.md`: 실제 시트 구조·입력/집계 방식·지원 기능. 예제 양식으로 작성.
- `progress.md`: 초기 설정의 현재 단계·근거·다음 행동.
- `policy.md`: 기본 규칙에서 달리 정한 개인 정책이 생긴 경우에만 생성.
- `records/`: 별도로 요청한 장기 회고·결정 기록이 생길 때 생성.

예제의 URL 입력칸을 실제 링크로 채우는 작업은 개인 사본에서만 합니다. 계좌·분류·기준통화·시작월·거래·잔액·운영 미결 목록은 Sheets의 실제 지정 위치에 둡니다. 설정 단계의 진행 상태와 매일 바뀌는 거래 처리 상태를 구분하세요.

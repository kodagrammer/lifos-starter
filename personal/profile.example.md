# 개인 환경 연결 양식

이 파일을 개인 Private 사본에서 `personal/profile.md`로 복사하고 채웁니다. 공개 원본은 수정하지 않습니다.

- 개인 GitHub 저장소 URL: [개인 URL 입력]
- Google Sheets 가계부 URL: [개인 URL 입력]
- 연습용 Google Sheets URL: [생성 후 개인 URL 입력]
- 선택 경로: [신규/기존]
- 개인 시트 운영지침: personal/finance-layout.md
- 개인 정책: 별도 정책이 없으면 공통 규칙 적용. 생기면 personal/policy.md 연결.
- 장기 기록: 요청에 따라 personal/records/에 생성.

기준통화·시작월·시간대·분류·계좌·잔액·운영 미결은 개인 시트 운영지침이 가리키는 실제 Sheets 위치에서 읽습니다. 여기에 수치를 복제하지 않습니다.
